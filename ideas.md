# Propuestas de Diseño: Nexus Fútbol & Business

## Contexto
Sitio web profesional para una consultoría legal y técnica deportiva. Marca: Nexus Fútbol & Business. Logo verde con escudo, balanza (legal) y fútbol. Público objetivo: futbolistas y directivos de clubes. Tono: profesional, confiable, estratégico.

## Diseño 1: Minimalismo Legal Corporativo

**Design Movement:** Corporativismo Suizo + Derecho Moderno

**Core Principles:**
- Tipografía clara y jerárquica: Montserrat Bold para títulos, Lato para cuerpo
- Espacios amplios y aire blanco: máxima legibilidad
- Grid simétrico con alineación perfecta
- Colores institucionales: Verde esmeralda (#1B7D5C), Gris carbón (#2C3E50), Blanco

**Color Philosophy:**
Verde esmeralda como color primario (confianza, estabilidad, crecimiento). Gris carbón para textos (seriedad legal). Blanco abundante (claridad, transparencia). Acentos dorados sutiles para destacar CTAs.

**Layout Paradigm:**
Estructura de dos columnas: navegación lateral fija izquierda, contenido principal derecho. Hero section con imagen de fondo verde gradiente suave + texto blanco superpuesto. Secciones alternadas (texto-imagen, imagen-texto).

**Signature Elements:**
- Líneas divisoras horizontales en verde esmeralda (separación clara entre secciones)
- Iconografía minimalista: escalas, balón, documento, persona
- Tarjetas con sombra suave y borde verde sutil

**Interaction Philosophy:**
Transiciones suaves al pasar el mouse. Botones con efecto de relleno de color (verde esmeralda). Hover states con cambio de sombra. Scroll revelador de contenido (fade-in).

**Animation:**
Entrada de elementos con fade-in + slide-up leve (200ms). Hover en botones: cambio de color + escala 1.05. Scroll parallax suave en hero section.

**Typography System:**
- Montserrat Bold 48px para H1 (títulos principales)
- Montserrat SemiBold 32px para H2 (subtítulos)
- Lato Regular 16px para párrafos
- Lato Medium 14px para labels y CTAs

## Diseño 2: Dinámico y Deportivo

**Design Movement:** Diseño Deportivo Moderno + Energía Futbolística

**Core Principles:**
- Tipografía audaz: Bebas Neue para títulos (impacto), Inter para cuerpo (legibilidad)
- Composición asimétrica con bloques de color
- Movimiento visual a través de diagonales y ángulos
- Colores vibrantes: Verde esmeralda + Naranja coral + Negro

**Color Philosophy:**
Verde esmeralda como base (profesionalismo). Naranja coral como acento energético (movimiento, pasión). Negro para contraste y autoridad. Degradados sutiles entre verde y negro en fondos.

**Layout Paradigm:**
Hero section con imagen diagonal (clip-path) que divide la pantalla. Secciones con bloques de color alternados. Tarjetas flotantes con sombra profunda. Navegación top bar con logo y menú hamburguesa.

**Signature Elements:**
- Diagonal cuts en secciones (clip-path: polygon)
- Iconos grandes y coloridos (verde, naranja, blanco)
- Tarjetas con esquinas redondeadas (16px) y sombra profunda
- Líneas diagonales como decoración

**Interaction Philosophy:**
Interacciones rápidas y responsivas. Botones con animación de "push" (escala + sombra). Hover en tarjetas con elevación. Scroll trigger para revelar elementos con animación.

**Animation:**
Entrada de elementos con scale-up + fade-in (300ms). Hover en tarjetas: elevación + cambio de sombra. Botones con ripple effect. Scroll parallax en hero.

**Typography System:**
- Bebas Neue 56px para H1 (impacto)
- Bebas Neue 36px para H2 (energía)
- Inter Regular 16px para párrafos
- Inter SemiBold 14px para CTAs

**Probability:** 0.07

## Diseño 3: Elegancia Sofisticada con Toque Deportivo

**Design Movement:** Lujo Minimalista + Detalles Deportivos

**Core Principles:**
- Tipografía refinada: Playfair Display para títulos (elegancia), Lato para cuerpo (claridad)
- Uso estratégico de espacios negativos
- Detalles sutiles: líneas finas, bordes delgados, texturas suaves
- Colores sofisticados: Verde esmeralda + Crema + Negro

**Color Philosophy:**
Verde esmeralda como color primario (profesionalismo + naturaleza). Crema (#F5F1E8) como fondo (calidez, lujo). Negro para textos (contraste elegante). Dorado muy suave para detalles (sofisticación).

**Layout Paradigm:**
Navegación top bar minimalista con logo. Hero section con imagen de fondo suave (fotografía deportiva con overlay verde translúcido) + texto blanco elegante. Secciones con contenido centrado, márgenes amplios. Tarjetas con borde fino y fondo crema.

**Signature Elements:**
- Líneas divisoras finas en verde esmeralda (elegancia)
- Iconografía minimalista en línea (stroke, no fill)
- Tarjetas con borde fino y sombra muy suave
- Tipografía serif para títulos (Playfair Display)

**Interaction Philosophy:**
Transiciones suaves y sutiles. Hover effects discretos (cambio de color suave, sin escala). Scroll smooth y revelador de contenido gradual. Botones con borde que se rellena al hover.

**Animation:**
Entrada de elementos con fade-in lento (400ms). Hover en botones: cambio de color + borde relleno. Scroll parallax muy suave. Transiciones de página con fade.

**Typography System:**
- Playfair Display 52px para H1 (elegancia)
- Playfair Display 36px para H2 (sofisticación)
- Lato Regular 16px para párrafos
- Lato Medium 14px para CTAs

## Decisión Final

**Diseño Seleccionado: Minimalismo Legal Corporativo (Opción 1)**

Este enfoque es el más adecuado para Nexus Fútbol & Business porque:
1. Transmite profesionalismo y confianza (esencial para un consultor legal)
2. La estructura clara facilita la navegación para directivos y jugadores
3. El verde esmeralda + gris carbón + blanco crea una identidad visual coherente con el logo
4. Las líneas divisoras y espacios amplios reflejan la "claridad legal" que ofreces
5. Es fácil de mantener y escalar a futuro

**Paleta de Colores:**
- Verde Esmeralda: #1B7D5C (primario, confianza)
- Gris Carbón: #2C3E50 (textos, autoridad)
- Blanco: #FFFFFF (fondo, aire)
- Dorado Sutil: #D4AF37 (acentos en CTAs)
- Gris Claro: #F8F9FA (fondos secundarios)

**Tipografía:**
- Montserrat (títulos, bold/semibold)
- Lato (cuerpo, regular/medium)
